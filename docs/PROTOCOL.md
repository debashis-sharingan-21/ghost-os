# GHOST.OS Telemetry Protocol Specification (ghost.v1)

## 1. Overview

GHOST.OS uses a versioned, newline-delimited JSON (JSON Lines / JSONL) telemetry protocol over 115200 baud UART (or simulated stream). Each telemetry frame is emitted as a single line terminated with a newline (`\n`).

- **Protocol Version**: `ghost.v1`
- **Encoding**: UTF-8
- **Transport**: Serial 8-N-1 (115200 bps default) / WebSocket / Replay File
- **Frequency**: 10 Hz (nominal 100 ms period)

---

## 2. Telemetry Frame Structure

Each frame conforms to the following JSON schema:

```json
{
  "proto": "ghost.v1",
  "seq": 1042,
  "ts_ms": 1729837201234,
  "device_id": "ESP32-GHOST-01",
  "simulated": false,
  "mpu6050": {
    "accel_x": 0.02,
    "accel_y": -0.01,
    "accel_z": 9.81,
    "accel_mag": 9.81,
    "gyro_x": 0.12,
    "gyro_y": -0.05,
    "gyro_z": 0.03,
    "temp_c": 26.5,
    "status": "OK"
  },
  "health": {
    "uptime_ms": 104200,
    "free_heap": 218400,
    "vcc_mv": 3290,
    "loop_hz": 10.0,
    "wifi_rssi": -55
  },
  "flags": {
    "calibrated": true,
    "anomaly_active": false,
    "error_code": 0
  }
}
```

### 2.1 Field Definitions

| Field | Type | Description |
|-------|------|-------------|
| `proto` | string | Protocol identifier and version (`ghost.v1`). Frames with unsupported versions are discarded with warning. |
| `seq` | integer | Monotonically increasing sequence number (0 to $2^{32}-1$). Used for packet drop detection. |
| `ts_ms` | integer | Timestamp in milliseconds (device epoch or system epoch ms). |
| `device_id` | string | Unique hardware or virtual identifier (e.g. `ESP32-GHOST-01` or `SIM-GHOST-VIRTUAL`). |
| `simulated` | boolean | `true` if generated by the deterministic telemetry simulator; `false` if acquired from real hardware. |

### 2.2 MPU6050 Subsystem

| Field | Type | Unit | Range | Description |
|-------|------|------|-------|-------------|
| `accel_x` | float | m/s² | -156.96 to +156.96 (±16g) | X-axis acceleration |
| `accel_y` | float | m/s² | -156.96 to +156.96 (±16g) | Y-axis acceleration |
| `accel_z` | float | m/s² | -156.96 to +156.96 (±16g) | Z-axis acceleration (~9.81 at rest flat) |
| `accel_mag` | float | m/s² | $\ge 0$ | Vector magnitude: $\sqrt{a_x^2 + a_y^2 + a_z^2}$ |
| `gyro_x` | float | °/s | -2000.0 to +2000.0 | Roll rate |
| `gyro_y` | float | °/s | -2000.0 to +2000.0 | Pitch rate |
| `gyro_z` | float | °/s | -2000.0 to +2000.0 | Yaw rate |
| `temp_c` | float | °C | -40.0 to +85.0 | MPU6050 internal die temperature |
| `status` | string | - | `"OK"`, `"DEGRADED"`, `"FAIL"`, `"FROZEN"` | Sensor operational state |

### 2.3 Hardware Health Subsystem

| Field | Type | Unit | Description |
|-------|------|------|-------------|
| `uptime_ms` | integer | ms | Microcontroller / simulator uptime |
| `free_heap` | integer | bytes | Free SRAM available to FreeRTOS |
| `vcc_mv` | integer | mV | Supply voltage rail measurement (nominally ~3300 mV) |
| `loop_hz` | float | Hz | Actual measured telemetry acquisition loop frequency |
| `wifi_rssi` | integer (optional)| dBm | Wi-Fi signal strength (if connected) |

### 2.4 Diagnostic Flags

| Field | Type | Description |
|-------|------|-------------|
| `calibrated` | boolean | Indicates whether gyro/accel bias calibration has completed |
| `anomaly_active`| boolean | Set if device firmware detects a local threshold breach |
| `error_code` | integer | Bitfield of active hardware error codes (0 = no error) |

---

## 3. Stream Resilience and Error Handling

1. **Non-JSON Noise Rejection**: Firmware boot logs, bootloader messages (`rst:0x1...`), and partial lines during UART connect/disconnect are stripped cleanly without crashing the stream parser.
2. **Line Delimitation**: Lines are delimited by `\n` or `\r\n`. Lines exceeding 4096 bytes are truncated and flagged as buffer overflow.
3. **Missing Fields**: If an optional health field is absent, default values are assigned by the Pydantic parser. Missing mandatory sensor fields trigger a parse error record.
4. **Sequence Discontinuity**: A gap in `seq` indicates dropped UART bytes or queue buffer overflow; recorded as a stream health event.
